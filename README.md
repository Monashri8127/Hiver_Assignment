# Hiver_Assignment

Customer support text classification with dataset expansion and evaluation.

## 📌 Overview
This project classifies customer support queries into categories such as payment issues, ride issues, and account issues.  
It was developed as part of the Hiver assignment to demonstrate text classification workflows.

## 📂 Dataset
- Source: Custom dataset of customer support queries  
- Size: ~100 rows  
- Balanced across categories  

## ⚙️ Methods
- Text preprocessing with TF-IDF  
- Models: Logistic Regression, Naive Bayes, SVM  
- Evaluation: Classification report, confusion matrix  

## 📊 Results
- Best performing model: Logistic Regression  
- Accuracy: 85%  
- Macro F1: 0.83
